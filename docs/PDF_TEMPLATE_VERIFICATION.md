# G76 단일 페이지 PDF 템플릿 검증

1. 가로·세로·정사각 비율의 단일 페이지 PDF를 각각 커스텀 템플릿으로 가져온다.
2. PDF가 3배율 PNG로 영구 저장되고 원본 비율이 유지되며 남는 영역은 흰색인지 확인한다.
3. 네 모서리와 중앙 기준점 위에 Pencil로 필기하고 화면·페이지 복제·PNG·PDF 내보내기의 위치 오차가 2px 이하인지 확인한다.
4. 앱 재시작, `.hanji` 백업 복원 및 Cloudflare 복원 뒤 템플릿과 필기 위치가 유지되는지 확인한다.
5. 2페이지 PDF를 선택하면 문서가 변경되지 않고 단일 페이지 PDF만 지원한다는 오류가 표시되는지 확인한다.
