# G78 자유 다각형 도형 검증

1. 다각형 도구로 삼각·오각·오목 육각형을 각각 20회 그리고 끝점에서 설정된 홀드 시간 이상 멈춘다.
2. 입력 경로가 RDP로 꼭짓점만 남도록 단순화되고 마지막 변이 첫 꼭짓점으로 자동 닫히며, 원본 경계를 2px 이내로 따르는지 확인한다.
3. 실선·점선과 채우기 없음·반투명·채움의 여섯 조합에서 점선 간격과 채우기가 오목 영역 바깥으로 새지 않는지 확인한다.
4. 색·굵기·불투명도·압력·기울기·생성 시각이 유지되고 실행 취소 한 번으로 자유 획, 다시 실행 한 번으로 다각형 전체가 복원되는지 확인한다.
5. 페이지·연속·줌 윈도우·확장 보드, 90도 회전, PNG/PDF, `.hanji` 및 Cloudflare 복원에서 도형과 레이어 순서가 일치하는지 확인한다.
6. 두 점 이하의 경로와 면적이 거의 없는 경로는 강제로 닫힌 도형으로 바뀌지 않고 원래 획으로 남아야 한다.
