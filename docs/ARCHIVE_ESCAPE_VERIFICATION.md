# G77 백업 탈출본 검증

1. 일반·PDF·회전·커스텀 템플릿·확장 보드가 섞인 노트 10권을 수동 `.hanji` 및 자동 백업으로 만든다.
2. ZIP을 Hanji 없이 열어 각 노트의 `escape/<notebook-id>/notebook.pdf`, 모든 페이지의 순번 PNG와 획 JSON이 존재하는지 확인한다.
3. PDF와 3배율 PNG의 배경·페이지 페인트·PencilKit 잉크·텍스트·이미지 위치가 앱 화면과 2px 이내인지 비교한다.
4. `manifest.json` 버전이 4이고 각 페이지 ID가 PNG·획 JSON 경로에 매핑되며 `errors`가 비어 있는지 확인한다.
5. 획 JSON에서 잉크 종류·RGBA·생성 시각·변환 행렬과 모든 제어점의 x/y·timeOffset·크기·불투명도·압력·방위각·고도각이 원본과 일치하는지 표본 100획을 비교한다.
6. 같은 파일을 새 설치에 복원해 원본 PKDrawing·PDF·이미지·오디오가 유지되는지 확인하고, 기존 v2·v3 백업도 정상 복원되는지 확인한다.
7. 자동 백업 중 한 페이지 렌더를 인위적으로 실패시켜도 원본·자산 백업은 생성되고 manifest 오류에 페이지 ID가 기록되는지 확인한다. 수동 내보내기에서는 실패가 사용자에게 전달되고 불완전 파일을 공유하지 않아야 한다.
