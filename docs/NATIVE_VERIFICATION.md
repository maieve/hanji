# iPad native verification

Windows에서는 iOS 프로젝트 생성과 Swift 컴파일이 지원되지 않는다. 네이티브 변경은 `.github/workflows/ios-build.yml`의 macOS 빌드가 authoritative gate다.

## Gates

- G1 Ink: Apple Notes와 동일 문장 30분, 지연 육안 차이 없음, 손바닥 오작동 0회.
- G2 OCR: 한국어 손글씨 100줄 recall 70% 이상. 미달 시 ML Kit Digital Ink 어댑터로 전환.
- G3 PDF: 200쪽 PDF에서 페이지 직접 이동 시트로 1·100·200쪽 및 범위 밖 값을 입력하고, 유효한 페이지만 정확히 이동하는지 확인한다. 이어 페이지 전환, 50–800% 확대, 잉크 좌표 일치 및 메모리 경고 없음.
- G4 Audio: 60분 녹음, 페이지 이동 후 스트로크 탭 시 목표 시각 ±250ms.
- G5 Backup: 앱 삭제 전 백업을 새 설치에 복원하고 PDF/원본 드로잉 수가 일치.
- G6 Pencil gestures: 일반 문장 50줄에서 긁어서 지우기 오탐 1회 이하, 의도한 지우기 성공률 90% 이상. 직선·화살표·원·사각형·삼각형을 각 20회 그리고 Quick Shapes 성공률 90% 이상, 실행 취소 1회로 원본 스트로크 복원.
- G7 Zoom Window: 2.5배 확대 상태로 가로 3구간과 세로 3줄을 연속 필기한다. 오른쪽 경계에서만 자동 전진하고 줄 끝에서 다음 줄로 이동하며, 확대 해제 후 스트로크 좌표·도구·지우개·오디오 타임스탬프가 유지된다.
- G8 PDF navigation: 목차와 내부/외부 링크가 포함된 PDF에서 PDF 페이지 순서를 섞고 일반 페이지와 다른 PDF 페이지를 중간에 넣은 뒤에도 목차 20개와 내부 링크 20개가 같은 원본 PDF의 정확한 `pdfPageIndex`로 이동해야 한다. 외부 링크 5개는 시스템 브라우저에서 열리고 Apple Pencil 입력은 링크를 열지 않는다.
- G9 Cloud restore: 100MB 초과 `.hanji` 백업을 R2 멀티파트로 업로드하고 새 설치에서 복원한다. 노트·페이지·PDF·오디오·플래시카드·태그·북마크 수와 대표 파일 SHA-256이 원본과 일치한다.
- G10 Hybrid canvas: 200쪽 PDF를 세로 연속 모드로 1→200→100쪽 순서로 이동하고 메모리 경고나 빈 캔버스가 없어야 한다. 일반 노트 끝에서 직접 스크롤했을 때 페이지가 정확히 1장만 자동 추가되고, 페이지 모드로 전환한 뒤 같은 페이지의 잉크·요소·현재 위치가 유지된다.
- G11 Custom template: 눈금 모서리에 기준점이 있는 900×636 PNG를 배경으로 가져와 네 모서리에 필기한 뒤 PNG/PDF와 `.hanji` 백업을 만든다. 내보낸 파일과 새 설치 복원본에서 배경·필기 기준점 오차가 2px 이하이고, 템플릿 교체·제거 후 잉크는 유지되어야 한다.
- G12 Page transfer: PDF 원본 37쪽에 잉크·텍스트·이미지·커스텀 템플릿과 녹음 중 스트로크 3개를 만든 뒤 다른 노트에 복사하고 이동한다. 대상에서 원본 37쪽이 표시되고 모든 요소·스트로크 오디오 탐색이 유지되며, 복사본 ID는 원본과 다르고 이동본 ID는 동일해야 한다. 마지막 한 페이지를 이동한 원본 노트에는 빈 페이지 1장이 남아야 한다.
- G13 Page rotation: 네 모서리 기준점이 있는 PDF·커스텀 템플릿 페이지에 회전 전후 각각 10획을 쓰고 90°씩 네 번 회전한다. 매 단계에서 PDF·배경·기존/신규 잉크·텍스트·이미지의 상대 오차가 2px 이하이고 터치 위치가 펜촉과 일치해야 한다. PNG/PDF 내보내기의 방향과 좌표가 화면과 같으며 네 번째 회전 후 원본 방향·PKDrawing 데이터가 유지되어야 한다.
- G14 Eraser return: 서로 다른 색·굵기의 필기 도구 7종 각각에서 지우개로 전환해 10회씩 지운다. 펜슬을 떼는 순간 직전 필기 도구의 종류·색·굵기·불투명도로 70/70회 복귀하고 지우개 한 획만 적용되어야 한다. `자동↩`을 끈 상태에서는 10/10회 지우개에 남아야 하며, 더블탭 전환은 설정과 무관하게 동작해야 한다.
- G15 Page grid: 일반·PDF·회전·커스텀 템플릿이 섞인 100쪽 노트에서 1·25·50·75·100쪽을 각각 10회 드래그 재배열한다. 놓은 순서와 실제 페이지 내용·PDF 원본 번호가 50/50회 일치하고 현재 페이지가 같은 ID를 유지해야 한다. 그리드의 북마크·복제·90° 회전·보내기·삭제·열기를 각 10회 수행해 중복 ID나 빈 노트가 생기지 않아야 한다. 오디오 타임라인 획이 있는 페이지를 복제·복사·이동하면 새 페이지 ID로 해당 획 참조가 복제되고 이동 원본 참조만 제거되어야 하며 녹음 파일과 다른 페이지 참조는 유지되어야 한다. 북마크와 회전은 Cloud 병합 및 `.hanji` 복원 후 유지되어야 한다. Split View 최소 폭에서 하단 동작을 가로 스크롤로 모두 실행할 수 있고 VoiceOver가 페이지 번호·북마크·회전 상태와 각 동작을 구분해 읽어야 한다.
- G16 Image crop: 가로·세로·정사각 이미지 각 3장을 삽입해 맞춤/채움 크롭과 90° 회전을 모든 조합으로 적용한다. 화면·PNG·PDF·`.hanji` 복원본의 크롭 경계와 방향이 2px 이내로 일치하고 네 번 회전 후 원본 방향으로 돌아와야 한다. 편집 전후 원본 이미지 파일의 SHA-256은 같아야 한다.
- G17 Ink replay: 녹음 전에 5획을 그리고, 60초 녹음 중 10초 간격으로 서로 다른 페이지에 6획을 추가한다. `잉크` 리플레이를 켜고 0·10·30·60초로 탐색했을 때 녹음 전 획은 항상 보이고 녹음 중 획은 생성 시각 ±250ms 안에서 순서대로 나타나야 한다. 리플레이 중 편집은 차단되고 끈 직후 전체 원본 PKDrawing과 SHA-256이 복원되어야 하며 페이지 모드와 연속 모드에서 결과가 같아야 한다.
- G18 Marker straight line: 형광펜 `홀드 직선`을 켜고 가로·세로·대각선 각 20획을 그린 뒤 끝점에서 0.35초 이상 멈춘다. 60/60획이 시작점과 끝점을 잇는 직선으로 교체되고 색·굵기·투명도·생성 시각이 유지되어야 하며 실행 취소 한 번으로 원래 자유곡선이 복원되어야 한다. 0.2초 이내에 떼거나 옵션을 끈 대조군 각 20획은 보정되지 않아야 하고 페이지·연속 모드 결과가 같아야 한다.
- G19 Dashed shapes: 직선·화살표·원·사각형·삼각형을 실선과 점선으로 각 10개씩 그린다. 점선은 곡선과 모서리 전체에서 12pt 선/7pt 간격이 끊김 없이 이어지고 색·굵기·투명도가 실선과 같아야 한다. 화면·PNG·PDF·`.hanji` 복원본에서 선 패턴과 좌표가 2px 이내로 일치하며 실행 취소/다시 실행 후에도 스타일이 유지되어야 한다.
- G20 Color picker: 시스템 컬러 피커에서 RGB 색상 10개를 선택하고 스포이드로 사진·PDF·기본 템플릿의 색상 각 10개를 찍는다. 적용된 잉크의 sRGB 값이 선택값과 채널당 ±1 이내로 일치하고 최근 색 목록에 중복 없이 최신순으로 남아야 한다. 피커를 취소하면 기존 색이 유지되며 다크 모드·Split View·페이지 및 연속 모드에서 피커 표시와 Pencil 입력 복귀가 정상이어야 한다.
- G21 Sticker collection: 서로 다른 이미지 20개를 직접 가져오고 페이지에 배치한 이미지 20개를 크롭·회전한 뒤 컬렉션에 보관한다. 앱 재시작 후 40개가 최신순으로 남고, 다른 노트의 페이지 및 연속 모드에 각 항목을 삽입했을 때 URI·맞춤/채움·회전·크기가 원본 설정과 일치해야 한다. 동일 설정을 다시 보관하면 중복 항목 대신 기존 항목이 맨 앞으로 이동하고 컬렉션에서 삭제해도 이미 배치된 이미지와 원본 파일은 유지되어야 한다.
- G22 Cloud page merge and conflict restore: 같은 노트의 페이지별 `updatedAt`이 서로 엇갈리는 두 백업과 한쪽에만 새 페이지가 있는 백업을 교차 복원한다. 각 페이지 최신본과 양쪽 전용 페이지가 한 원본 노트에 모두 합쳐지고, 내용이 달라 패배한 페이지 버전만 `(페이지 충돌 사본)`으로 보존되어야 한다. 두 기기에서 서로 다른 시각에 페이지를 재배열·삽입·복제·삭제·이동한 뒤 병합하면 가장 최신 `pageOrderUpdatedAt`의 순서를 기준으로 반대쪽 전용 페이지만 상대 순서대로 추가되고, 더 늦은 일반 내용 수정은 페이지 순서를 덮어쓰지 않아야 한다. 사본의 페이지·오디오 스트로크 참조 ID는 내부에서만 새 ID로 매핑되어야 한다. 같은 백업을 다시 복원해도 동일 패배 페이지가 중복 생성되지 않아야 하며 녹음 생성 시각·플래시카드 ID별 항목도 유실 없이 합쳐져야 한다. OCR 캐시와 복원 경로만 다른 페이지는 충돌로 판정하지 않아야 한다.
- G23 On-device transcript: 조용한 방·일반 강의실·배경 소음 환경에서 한국어 표준 문장 각 10분을 녹음하고 `전사`를 실행한다. 네트워크를 끈 상태에서도 전사가 완료되고 텍스트와 단어별 시작 시각·길이·confidence가 저장되어야 한다. 앱 재시작·`.hanji` 백업 복원 뒤 전사문이 유지되고 30개 기준 WER을 기록한다. `supportsOnDeviceRecognition=false`인 기기에서는 네트워크 전사로 폴백하지 않고 지원 불가 메시지를 표시해야 한다.
- G24 Transcript navigation: 10분 전사문에서 시작·중간·끝 구간의 단어 각 20개를 탭한다. 재생 위치가 저장된 단어 시작 시각 ±250ms로 이동하고 해당 단어가 재생 중 강조되어야 한다. 전사문에만 존재하고 OCR·제목·태그에는 없는 한국어 검색어 20개를 서재에서 검색했을 때 모두 해당 노트 첫 페이지로 이동하며, 전사문 삭제 또는 노트 삭제 뒤 검색 인덱스에서도 사라져야 한다.
- G25 Advanced lasso: Apple Pencil로 사각 선택 영역 30개를 만들고 경계에 걸친 획과 내부 획의 선택 수가 예상값과 일치하는지 확인한다. 선택 획 색상 변경·삭제는 비선택 획을 바꾸지 않고 실행 취소 한 번으로 원본을 복원해야 한다. 한국어 손글씨 100개 영역을 텍스트로 변환했을 때 선택 획만 제거되고 같은 위치에 텍스트 상자가 생기며 G2 기준을 만족해야 한다. 손가락 스크롤은 선택 제스처와 충돌하지 않고 페이지·연속 모드에서 결과가 같아야 한다.
- G26 Circle-to-lasso: 펜 도구에서 기존 획 1·10·100개를 둘러싸는 원과 타원을 각 20회 그린다. 시작·끝 간격이 대각선의 18% 이내이고 내부 획이 있을 때만 제스처 획이 제거되어 내부 중심점 기준 획이 선택되고 도구가 올가미로 전환되어야 한다. 빈 원·열린 원·가로세로 비율 2.2 초과·옵션 OFF 대조군 각 20회는 일반 잉크로 남아야 하며 일반 문장 100줄에서 오탐은 1회 이하여야 한다.
- G27 Lasso copy and duplicate: 색·굵기·투명도·펜 종류가 다른 50획을 선택해 PNG 복사를 실행한다. 다른 앱에 붙여 넣은 이미지가 3배율 투명 배경이고 선택 경계 여백이 10pt이며 화면과 2px 이내로 일치해야 한다. 같은 선택을 20회 복제하면 각 복제본이 우하단 18pt에 생성되고 원본 스타일과 경로 생성 시각을 유지하며 새 복제본만 재선택되어야 한다. 실행 취소/다시 실행 한 번으로 복제 전체가 제거/복원되어야 한다.
- G28 Lasso move: 색·굵기·투명도·펜 종류가 다른 50획을 선택한 뒤 선택 테두리 안을 Pencil로 20회 끌어 이동한다. 이동 중 테두리와 모든 선택 획이 Pencil을 따라가고 비선택 획은 변하지 않아야 하며, 실행 취소/다시 실행 한 번으로 전체 이동이 원위치/최종 위치를 정확히 왕복해야 한다. 선택 밖에서 끌면 새 사각 선택을 시작하고 제스처 취소 시 원본과 선택 상태가 보존되어야 한다.
- G29 Native cut and paste: 서로 다른 PencilKit 잉크 50획을 선택해 복사하면 Hanji 내부 전용 PKDrawing 데이터와 타 앱용 투명 PNG가 동시에 클립보드에 있어야 한다. 잘라내기는 선택 획만 제거하고 한 번의 실행 취소로 복원되어야 한다. 같은 페이지와 다른 페이지에서 20회 붙여넣으면 매번 우하단으로 18pt씩 계단 이동하고 원본 잉크·압력·기울기·생성 시각을 유지한 채 새 획만 선택되어야 하며, 붙여넣기마다 실행 취소/다시 실행이 독립적으로 동작해야 한다. 호환 데이터가 없는 클립보드에서는 문서가 변하지 않고 오류 햅틱만 발생해야 한다.

- G43 New-page placement: 서로 다른 내용의 20페이지 노트에서 1·10·20페이지를 열고 설정의 `현재 페이지 뒤`로 각각 10회 추가한다. 새 페이지가 선택 페이지 바로 뒤에 생기고 즉시 열린 상태가 되며 기존 페이지의 ID·내용·순서가 유지되어야 한다. 같은 절차를 `문서 맨 끝`으로 반복하면 항상 마지막에 추가되고 새 마지막 페이지로 이동해야 한다. 연속 모드 끝까지 직접 스크롤한 자동 추가는 설정과 관계없이 끝에 정확히 한 장만 생겨야 하며, 기본 템플릿·다크 잉크 설정이 새 페이지에 적용되어야 한다. 앱 재시작 후 삽입 위치 선택이 유지되고 Split View·페이지 모드·연속 모드에서 결과가 같아야 한다.
- G44 Automatic backup interval: 자동 백업 주기를 5·15·30·60분으로 각각 선택하고 편집 후 15초 이상 유휴 상태를 만든다. 마지막 백업보다 선택 주기 미만이면 새 파일과 R2 업로드가 생기지 않고, 주기를 지난 첫 유휴 시점에는 정확히 한 개가 생성·업로드되어야 한다. 편집을 연속으로 수행하면 유휴 타이머가 재시작되어 편집 중 압축 작업이 시작되지 않아야 하며 `지금 백업`은 주기와 관계없이 즉시 실행되어야 한다. 앱 강제 종료 후 주기 선택이 유지되고 잘못된 이전 설정값은 30분으로 안전하게 복구되어야 하며 G38 보관 개수 정책과 동시에 만족해야 한다.
- G45 Editor export escape hatch: PDF·커스텀 템플릿·페이지 페인트·필기·텍스트·이미지·클리핑·60분 오디오·전사·플래시카드가 포함된 노트에서 에디터 내보내기 메뉴의 세 형식을 각각 실행한다. 노트 PDF의 페이지 수·회전·레이어 좌표는 화면과 2px 이내로 일치하고, 현재 페이지 PNG는 3배율이며, 원본 `.hanji`에는 해당 노트 하나와 모든 참조 자산 및 PencilKit 원본이 포함되어야 한다. 새 설치에서 `.hanji`를 복원했을 때 G5의 수와 대표 파일 SHA-256이 일치하고 필기 편집·오디오 탐색이 계속 가능해야 한다. 내보내기 진행 중 중복 탭은 파일을 중복 생성하지 않고 취소·공유 시트 닫기·저장 공간 부족 오류가 노트 데이터를 변경하지 않아야 한다.
- G46 Folder lifecycle: 3단계 중첩 폴더에 서로 다른 노트 20개를 배치하고 가운데 폴더를 길게 눌러 이름을 바꾼다. 하위 폴더와 모든 노트가 새 경로로 이동하고 즐겨찾기·최근 문서·검색 결과·열린 노트 내용은 변하지 않아야 한다. 같은 위치의 기존 이름으로 변경할 때는 거부되어야 한다. 가운데 폴더 삭제 시 직접 포함된 노트는 상위 폴더로, 하위 폴더와 그 노트는 상대 경로를 유지한 채 상위 폴더 아래로 이동해야 한다. 최상위 폴더 삭제 시에는 `내 노트`로 이동하며 어떤 노트·페이지·자산도 삭제되지 않아야 한다. 앱 재시작과 `.hanji` 백업 복원 뒤 경로가 유지되고 Split View 최소 폭에서는 상단 폴더 칩을 통해 모든 이동 결과에 접근할 수 있어야 한다.
- G47 Per-note biometric lock: 서로 다른 노트 10개 중 5개만 노트 설정에서 잠근다. 잠금 설정·해제 모두 Face ID·Touch ID 또는 기기 암호 성공 뒤에만 반영되고 취소·실패 시 기존 상태가 유지되어야 한다. 잠긴 노트는 카드·제목 검색 결과·OCR 검색 결과·열린 문서 탭에서 진입할 때 인증 전 페이지가 한 프레임도 표시되지 않아야 하며, 서재 검색에서는 제목·태그만 노출되고 OCR·전사·본문 스니펫은 숨겨져야 한다. 같은 활성 세션에서는 재인증 없이 탭을 왕복할 수 있지만 앱을 백그라운드로 보낸 뒤 돌아오면 현재 잠긴 노트와 열려 있던 모든 잠긴 탭이 다시 인증을 요구해야 한다. 앱 전체 잠금과 노트 잠금을 동시에 켠 경우 앱 전체 인증 후 노트 인증이 순서대로 동작하고, `.hanji` 백업 복원 뒤 잠금 속성이 유지되어야 한다.
- G48 Library sort and view: 이름에 한글·영문·숫자가 섞이고 생성일·수정일·페이지 수가 서로 다른 노트 100개를 준비한다. 최근 수정·이름·생성일·페이지 수 정렬 결과가 각 기준과 일치하고 동률은 수정일 역순으로 안정적으로 결정되어야 하며 `최근 문서`에서는 선택 정렬보다 마지막 열람 시각이 우선해야 한다. 서재 카드·검색 결과·새 노트·PDF 가져오기·문서 탭·원문 링크·참조 문서로 서로 다른 노트를 차례로 열면 수정 시각을 바꾸지 않고 실제 열람 순서대로 최근 문서 상단에 나타나야 한다. 서로 다른 두 기기에서 같은 노트를 열고 Cloud 병합하면 더 최신 열람 시각이 보존되고 앱 및 `.hanji` 백업 복원 뒤에도 순서가 같아야 한다. 카드/목록 보기를 각각 선택해 노트 열기·즐겨찾기·설정·폴더·태그·검색 페이지 점프가 동일하게 동작해야 한다. 잠긴 노트는 인증 성공 후에만 최근 시각이 바뀌고 두 보기 모두 잠금 표시가 있으며 OCR·전사 스니펫을 노출하지 않아야 한다. 앱 강제 종료 뒤 정렬과 보기 선택이 유지되고 세로·가로 및 Split View 최소 폭에서 정렬 버튼은 가로 스크롤로 모두 접근 가능하며 목록 행이 화면 밖으로 잘리지 않아야 한다.
- G49 Focus toolbar auto-hide: 페이지 모드와 연속 모드에서 집중 모드에 진입하면 툴바가 즉시 표시되고 마지막 Pencil 필기 또는 툴바 터치 후 2.0초±150ms에 숨겨져야 한다. 1.5초 간격으로 20획을 연속 작성하는 동안에는 숨지 않고 마지막 획 이후에만 사라져야 한다. 숨겨진 상태의 손잡이를 누르면 모든 도구에 다시 접근할 수 있고 툴바 조작마다 2초 타이머가 재시작되어야 하며 축소 버튼으로 즉시 일반 모드로 돌아와야 한다. 툴바 표시·숨김 전후 캔버스 크기, PDF·필기 좌표, 현재 페이지, 선택 영역, 오디오 녹음이 변하지 않아야 한다. 왼손 모드·Split View 최소 폭·화면 회전에서도 손잡이가 화면 안에 있고 앱을 백그라운드로 보냈다 돌아와도 중복 타이머나 깜빡임이 없어야 한다.
- G50 Optional page-turn haptics: 설정에서 페이지 넘김 햅틱을 켜고 페이지 모드 썸네일·페이지 그리드·PDF 목차·내부 링크·문서 검색 결과로 서로 다른 페이지를 각 20회 이동한다. 각 이동에 가벼운 selection 햅틱이 정확히 한 번 발생하고 같은 페이지 재선택·노트 최초 열기·페이지 삭제 후 인덱스 보정·백업 복원에는 발생하지 않아야 한다. 연속 모드에서 100페이지를 천천히 스크롤하면 실제 활성 페이지 경계를 넘을 때마다 한 번만 발생하고 빠른 플링에서도 동일 인덱스 중복 진동이 없어야 한다. 옵션을 끈 뒤 같은 절차를 반복하면 진동이 0회여야 하며 앱 강제 종료 후 선택이 유지되어야 한다. 햅틱을 지원하지 않거나 시스템 햅틱을 끈 기기에서도 페이지 이동은 지연·오류 없이 완료되어야 한다.
- G51 Shape hold requirement: 도형 도구에서 `홀드 필요`를 켜고 직선·화살표·원·사각형·삼각형을 각각 끝점 정지 0.2초와 0.5초로 20개씩 그린다. 0.2초 대조군 100개는 원래 자유 획로 남고 0.5초 실험군 100개만 정형 도형으로 교체되어야 하며 스냅 시 가벼운 햅틱이 한 번 발생해야 한다. 옵션을 끈 뒤 같은 도형을 정지 없이 각 20개 그리면 100개 모두 즉시 스냅되어야 한다. 실선·점선, 색·굵기·불투명도, Pencil 압력·기울기, 생성 시각과 실행 취소 한 번의 원본 복원이 두 모드에서 유지되어야 한다. 페이지·연속 모드 및 앱 재시작 후 옵션 상태가 같고 일반 펜·형광펜 홀드 직선·긁어서 지우기 판정에는 영향을 주지 않아야 한다.

## Device test procedure

- G52 Configurable Pencil gestures: 설정에서 Apple Pencil 더블 탭과 Pencil Pro 스퀴즈를 각각 `지우개 전환`, `실행 취소`, `다시 실행`, `도구 막대 표시`, `사용 안 함`으로 지정한다. 페이지 모드와 연속 모드에서 각 동작이 정확히 한 번만 실행되어야 하며, 집중 모드의 `도구 막대 표시`는 숨겨진 도구 막대를 다시 표시해야 한다. 앱을 강제 종료하고 다시 열어도 선택값이 유지되어야 한다. 스퀴즈를 지원하지 않는 Pencil에서는 오류나 오동작이 없어야 한다.
- G53 Multi-touch history gestures: 설정에서 `두 손가락 탭으로 실행 취소`와 `세 손가락 탭으로 다시 실행`을 켠다. 페이지 모드와 연속 모드에서 필기 20획을 만든 뒤 두 손가락 탭 10회와 세 손가락 탭 10회를 수행하면 매번 정확히 한 획씩 제거·복원되어야 한다. 핀치 줌, 두 손가락 팬, 시스템 세 손가락 스와이프 실행 취소·다시 실행은 그대로 동작하고 손가락 탭이 잉크 획을 만들지 않아야 한다. 각 설정을 끄면 해당 탭만 무시되며 앱을 강제 종료한 뒤에도 선택값이 유지되어야 한다.
- G54 Pencil Pro temporary eraser: Pencil Pro 스퀴즈 동작을 `누르는 동안 지우개`로 설정하고 펜·연필·형광펜 각각으로 필기한다. 스퀴즈를 누르는 즉시 벡터 지우개로 바뀌고 누른 채 기존 획을 지울 수 있으며, 손을 놓거나 스퀴즈가 취소되면 정확히 직전 도구·색·굵기·불투명도로 복귀해야 한다. 이미 지우개인 상태에서 스퀴즈하거나 빠르게 50회 반복해도 도구가 뒤집히거나 고정되지 않아야 한다. 페이지 모드·연속 모드·줌 윈도우에서 동일해야 하며 Pencil Pro가 아닌 기기에서는 설정값만 유지되고 오류가 없어야 한다.
- G55 Respect Pencil system preferences: Hanji의 더블 탭과 스퀴즈 동작을 각각 `시스템 설정 따르기`로 지정한다. iPad 설정에서 Apple Pencil 동작을 `현재 도구와 지우개 간 전환`, `현재 도구와 마지막 사용 도구 간 전환`, 팔레트 표시, 끄기로 차례로 바꾸고 앱을 다시 활성화한 뒤 각 제스처를 20회 수행한다. 지우개는 왕복 전환되고 이전 도구는 도구·색·굵기·불투명도를 교환하며, 팔레트 계열은 집중 모드의 Hanji 툴바를 표시하고 끄기는 아무 상태도 바꾸지 않아야 한다. 지우개 자동 복귀는 더블 탭 사용자 지정이 실행 취소·다시 실행이어도 항상 직전 펜으로만 복귀해야 한다.
- G56 Shape endpoint connections: 도형 도구의 실선·점선 직선과 화살표를 1·4·20pt 굵기로 각각 그리고 기존 도형 끝점에서 5·11·13·23·25pt 떨어진 위치에 새 선을 시작하거나 끝낸다. 굵기별 12–24pt 허용 거리 안의 가장 가까운 기존 저복잡도 도형 제어점에만 정확히 연결되고 바깥 점은 원래 위치를 유지해야 한다. 시작·끝을 같은 점에 붙여 선이 사라져서는 안 되며 사각형·삼각형·타원 자체의 형상은 변하지 않아야 한다. 실행 취소 한 번은 연결된 합성 도형을 원래 자유 획으로 복원하고 페이지·연속·줌 윈도우에서 결과가 같아야 한다.
- G57 Three-level template spacing: 줄·모눈·도트·코넬·다크 템플릿의 간격을 각각 `좁게` 24pt, `보통` 32pt, `넓게` 40pt로 바꾸고 페이지별로 서로 다른 조합 50개를 만든다. 화면, 페이지/연속 모드, 90·180·270도 회전, 3배 PNG, PDF 내보내기에서 선·점 간격과 필기 좌표가 2px 이내로 일치해야 한다. 페이지 복제·다른 노트 전송·Cloud merge·`.hanji` 백업 복원 후 선택값이 유지되고 이전 버전 페이지의 누락값은 `보통`으로 안전하게 이관되어야 한다. 설정의 새 페이지 기본 간격은 이후 생성되는 페이지에만 적용되고 기존 페이지 및 원본 PDF·커스텀 템플릿에는 영향을 주지 않아야 한다.

- G60 Fine brush controls and per-tool memory: 볼펜·만년필·모노라인·연필·크레용·수채화·형광펜 각각에서 굵기 슬라이더를 Pencil과 손가락으로 양 끝까지 끌어 0.5–40pt 전 범위를 조절하고, 도구별 3단 굵기 프리셋을 모두 선택하며, `−/+`로 불투명도를 5–100% 전 범위까지 조절한다. 슬라이더는 낮은 굵기를 정밀하게 선택할 수 있어야 하고 VoiceOver 조절 동작으로 증감 가능해야 한다. 경계에서 20회 더 조작해도 범위를 벗어나거나 0 굵기가 되지 않아야 하며, 화면 표시값과 PencilKit 결과가 각각 0.1pt·1% 이내로 일치해야 한다. 각 도구를 서로 다른 색·굵기·불투명도로 설정한 뒤 100회 전환하고 앱을 강제 종료해 다시 열어도 도구별 마지막 조합이 복원되어야 한다. 프리셋 선택과 HEX/시스템 컬러 변경도 해당 도구의 마지막 조합을 갱신하고 지우개·라쏘·도형 전환은 저장된 잉크 조합을 덮어쓰지 않아야 한다. 페이지·연속·줌 윈도우에서 같은 설정으로 20획씩 그렸을 때 렌더링과 PDF/PNG 내보내기 결과가 일치해야 한다.
- G61 Tool preset management: 도구 슬롯 관리에서 서로 다른 펜 12개를 저장하고 각 슬롯의 이름을 한글·영문·숫자 혼합 24자까지 바꾼다. 위/아래 이동으로 첫·중간·마지막 슬롯을 각각 20회 재정렬하고 현재 도구로 덮어쓴 뒤 색·굵기·불투명도·도구 종류가 즉시 미리보기와 실제 PencilKit 획에 일치해야 한다. 임의 슬롯 6개를 삭제해도 나머지 ID와 상대 순서는 유지되고 빈 이름은 저장되지 않아야 한다. 앱 강제 종료·백그라운드 복귀 후 이름·순서·설정이 유지되며, Split View 최소 폭에서 모든 행과 버튼에 스크롤로 접근 가능하고 VoiceOver가 슬롯 이름과 각 동작을 구분해 읽어야 한다. 프리셋 선택은 도구별 마지막 설정도 갱신하며 지우개·라쏘·도형 상태에서는 덮어쓰기만 비활성화되고 기존 슬롯은 손상되지 않아야 한다.
- G62 Shape fill styles: 원·사각형·삼각형을 외곽선 `실선/점선`과 채우기 `없음/반투명/채움`의 6개 조합으로 각각 20개씩 만든다. 채우기 획은 외곽선보다 먼저 생성되어 경계 밖으로 2px 이상 넘지 않고 반투명 20%·채움 72%의 시각 농도가 화면·3배 PNG·PDF에서 채널당 ±2 이내로 일치해야 한다. 색·굵기·불투명도와 생성 시각이 유지되고 한 번의 실행 취소/다시 실행으로 채우기와 외곽선 전체가 함께 왕복해야 한다. 선·화살표에서는 채우기 버튼이 비활성화되고 추가 채우기 획이 생기지 않아야 한다. 페이지·연속·줌 윈도우, 90° 회전, `.hanji` 백업 복원과 Cloud merge 후 모양·레이어 순서·농도가 같고 200개 도형을 만든 뒤에도 Pencil 지연이나 메모리 경고가 없어야 한다.
- G63 Lasso-to-flashcard: 한국어·영어 손글씨 Q/A 영역 각 50개를 올가미로 선택하고 `플래시카드 질문`을 실행한다. 선택 획은 삭제·이동되지 않은 채 Vision OCR 결과의 앞뒤 공백과 연속 줄바꿈만 정리되어 플래시카드 질문 입력란에 즉시 채워지고, 사용자가 정답을 입력해 저장하면 해당 노트의 SRS 카드가 정확히 한 장 생성되어야 한다. 빈 OCR 결과에서는 카드 화면이나 빈 카드가 생성되지 않아야 하며 질문은 500자로 안전하게 제한되어야 한다. 취소 후 다시 실행, 페이지·연속·줌 윈도우, 앱 재시작과 `.hanji`/Cloud 복원 뒤 질문·정답·복습 일정이 유지되어야 한다. 텍스트 변환 동작은 기존처럼 페이지 텍스트 요소를 만들고 플래시카드 동작과 섞이지 않아야 하며, VoiceOver가 두 동작을 서로 다른 이름으로 읽어야 한다.

PDF 페이지에서는 확장 버튼이 비활성화되고 4×4 경계에서 추가 확장이 무시되어야 하며 1000획·100개 요소가 있는 보드에서 흰 화면이나 메모리 경고가 없어야 한다.
- G65 Split reference document: 서로 다른 일반 노트·PDF 노트를 탭으로 5개 열고 비활성 탭의 참조 아이콘을 눌러 현재 편집 문서 위 오른쪽 참조 패널에 차례로 표시한다. 참조 패널은 배경·PDF·필기·텍스트·이미지·확장 보드를 화면과 2px 이내로 읽기 전용 렌더링하고 Pencil·손가락 입력으로 어떤 원본 데이터도 변경하지 않아야 한다. 참조 페이지 이전/다음을 각 50회 이동한 뒤 패널을 닫고 다시 열면 노트별 마지막 페이지가 복원되고 현재 편집 문서의 페이지·선택·실행 취소 기록·오디오 녹음은 변하지 않아야 한다. 잠긴 노트는 Face ID/암호 인증 성공 뒤에만 참조할 수 있고 현재 활성 노트 자체·닫힌/삭제된 탭은 참조되지 않아야 한다. 760pt 미만 폭에서는 패널이 92% 오버레이로 모든 버튼을 유지하고 넓은 화면에서는 44%로 표시되며, 회전·Split View·페이지/연속 모드·50–800% 확대에서 크래시나 좌표 이동이 없어야 한다.

- G68 Flashcard editing: 복습 전·후의 텍스트 카드와 이미지 카드를 각각 20장 편집해 질문·정답 변경, 이미지 제거, 편집 취소, 편집 중 삭제를 수행한다. 저장 시 카드 ID·생성 시각·복습 횟수·난이도·다음 복습일은 그대로이고 내용과 `updatedAt`만 바뀌어야 하며 Cloud merge에서는 더 최신 편집본이 선택되어야 한다. 취소는 어떤 필드도 변경하지 않고 편집 중인 행은 색상과 VoiceOver 편집 버튼 이름으로 구분되어야 한다. 앱 재시작과 `.hanji`/Cloud 복원 후에도 편집 내용과 기존 SRS 일정이 유지되어야 한다.
- G69 Page Q/A flashcard: 기본·PDF·회전·커스텀 템플릿·4×4 보드 페이지에서 위쪽에 질문, 아래쪽에 정답을 작성하고 `현재 페이지 Q/A 카드`를 실행한다. 화면의 배경·페이지 페인트·필기·텍스트·이미지가 3배율 전체 페이지 PNG와 먼저 일치한 뒤 정확히 50% 경계에서 두 이미지로 분할되어야 한다. 복습 앞면에는 위쪽만 보이고 탭 전에는 아래쪽 픽셀이 노출되지 않으며, 탭 뒤 정답 이미지와 4단계 평점이 표시되어야 한다. 원본 페이지 수정·삭제 후에도 생성 당시 카드 스냅샷은 유지되고 앱 재시작, `.hanji`/자동 백업/Cloudflare R2 복원 후 질문·정답 이미지 SHA-256과 SRS 일정이 일치해야 한다. 빠른 중복 탭은 버튼 잠금으로 카드 한 장만 생성하고 실패 시 반쪽 파일이나 빈 카드를 남기지 않아야 한다.
- G70 Lasso content filters: 잉크·텍스트·이미지가 서로 겹치거나 경계에 걸친 페이지 30개에서 올가미 필터 8개 조합을 각각 시험한다. 켜진 종류 중 선택 경계와 교차하는 항목만 선택 수와 청록색 강조에 포함되고 꺼진 종류는 이동·삭제·복제·잘라내기·붙여넣기·색 변경·축소·확대·회전 동작에서 변하지 않아야 한다. 요소만 있는 영역과 잉크만 있는 영역도 선택 가능해야 하며 텍스트 색 변경은 글자색만, 이미지 회전은 90도 단위로 적용되어야 한다. 페이지 간 요소 붙여넣기는 새 ID와 2% 오프셋을 사용하고 원본 URI·텍스트·크기를 보존해야 한다. 자유형·사각형, 페이지·연속·줌 윈도우·4×4 보드에서 경계 좌표 오차가 2px 이내이고 필터 상태는 도구 전환과 앱 재시작 후 유지되어야 한다.
- G71 Q/A paper template: 에디터와 새 페이지 기본 설정에서 `Q/A 카드` 템플릿을 각각 선택해 일반·회전·4×4 페이지를 20장 만든다. 화면·웹 PNG/PDF·iPad PNG/PDF에서 QUESTION/ANSWER 레이블과 50% 구분선이 동일 위치에 표시되고, 필기·텍스트·이미지는 구분선 위에 자연스럽게 합성되어야 한다. 해당 페이지를 Q/A 카드로 생성하면 질문 이미지의 마지막 픽셀 행과 정답 이미지의 첫 픽셀 행이 정확히 구분선 경계에 맞아 중복·누락이 없어야 한다. 템플릿 변경·페이지 복제·다른 노트 전송·앱 재시작·`.hanji`/Cloud 복원 후 템플릿 값이 유지되고 기존 페이지 콘텐츠 좌표는 변하지 않아야 한다.
- G72 Mixed lasso drag: 잉크·텍스트·이미지를 함께 선택한 경우와 각 종류만 선택한 경우를 페이지·연속·줌 윈도우·4×4 보드에서 각각 30회 끌어 이동한다. 선택 경계 내부를 Pencil로 누르는 순간 새 선택을 시작하지 않고 모든 선택 항목이 동일한 정규화 델타로 60fps 이동하며, 비선택 항목은 변하지 않아야 한다. 요소만 선택한 상태에서도 네이티브 선택 경계가 드래그를 시작하고 캔버스 가장자리에서는 각 요소의 너비·높이를 고려해 0–1 범위 안에 고정되어야 한다. Pencil을 놓은 최종 잉크 경계와 텍스트·이미지 경계 오차는 2px 이하이고 취소 시 시작 위치로 돌아가며, 100회 연속 이동 뒤에도 요소 ID·내용·이미지 URI와 PencilKit 획 속성이 유지되어야 한다.
- G73 Atomic mixed-selection history: 잉크·텍스트·이미지 혼합 선택과 요소 전용 선택에서 이동·삭제·잘라내기·붙여넣기·복제·색 변경·축소·확대·회전을 각각 20회 수행한다. 실행 취소 한 번으로 해당 작업의 모든 잉크와 요소가 동시에 직전 상태로 돌아가고 다시 실행 한 번으로 최종 상태가 복원되어야 한다. 요소 전용 작업의 실행 취소는 이전 PencilKit 획을 잘못 제거하지 않고, 혼합 작업은 네이티브 UndoManager와 요소 스냅샷을 함께 진행해야 한다. 페이지 전환·연속 모드·앱 백그라운드 복귀 뒤에도 바로 직전 작업은 복원 가능하며, undo/redo 100회 왕복 후 요소 순서·ID·URI·텍스트와 PKStroke 압력·기울기·생성 시각이 원본과 일치해야 한다.
- G74 Non-destructive image crop: 가로·세로·정사각 사진 각 10장을 채움 모드로 전환해 1–4배 확대와 상하좌우 초점 이동을 경계까지 반복한다. cropZoom은 1–4, cropX/cropY는 -1–1로 고정되고 원본 이미지 파일과 URI 및 SHA-256은 변하지 않아야 한다. 화면·스티커 미리보기·재삽입·웹/iPad 3배 PNG·PDF에서 회전·채움·확대·초점 위치가 2px 이내로 일치하고 맞춤 모드에서는 저장된 크롭값이 렌더에 영향을 주지 않아야 한다. 페이지 복제·다른 노트 전송·앱 재시작·`.hanji`/Cloud 복원 후 크롭 값이 유지되며 크롭 변경을 100회 실행 취소/다시 실행해도 원본 화질과 좌표가 유지되어야 한다.

1. `main`의 최신 `iOS Native Build`가 성공했는지 확인하고 unsigned IPA artifact를 내려받는다. 함께 들어 있는 `YoojinNote-build.txt`와 `YoojinNote-device-checklist.md`를 보존한다.
2. [IPAD_INSTALL.md](./IPAD_INSTALL.md)에 따라 AltServer/SideStore로 동일 빌드를 설치한다.
3. iPadOS 17 이상 실제 iPad와 Apple Pencil로 G1–G16을 순서대로 수행한다.
4. 생성된 체크리스트에 기기 모델, iPadOS 버전, Pencil 모델, 성공 횟수/전체 횟수, 화면 녹화 또는 샘플 파일을 기록한다.
5. G1/G2/G3 중 하나라도 실패하면 필기 앱 완성으로 판정하지 않는다. PDF G3 실패 시 설계의 Plan B인 페이지 이미지 렌더 방식으로 전환한다.
